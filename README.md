# Harf

An Uzbek alphabet conversion website and preview Windows input helper.
Original implementation; the linked UzKlaviatura project was inspected for
requirements and alphabet mappings, but its source/assets were not copied.

## Website

Static files are under `dist/`. No backend, accounts, paid APIs or database needed.
Serve that directory through GitHub Pages or another static host. The converter
runs locally and supports old/new Latin conversion, case, apostrophe variants,
link/email preservation, UTF-8 text imports, copying and .txt export.
Font loading uses Google Fonts, with system fallback. User text is not uploaded.

Run `node tests/converter.test.cjs` and `node --check dist/app.js` to verify logic.
The desktop source bundle is generated by `python3 scripts/package.py`.

## Windows status

See `desktop/README.md`. C# helper, per-user self-installation code, a build script
and GitHub Actions builds are provided. The first preview compiled successfully
on a Windows runner and passed converter self-tests. Preview installers are under
[Releases](https://github.com/codersirojiddin/alifbonew/releases). Manual Windows
installation, typing and uninstallation checks remain pending. A real OS keyboard
layout DLL is not implemented; this is a background input helper.

## GitHub

To host the website, publish `dist/` with GitHub Pages. To build the Windows source,
push desktop changes to main or manually run the Windows workflow. It compiles,
runs converter tests, uploads artifacts, and publishes a prerelease with the
installer and SHA-256 hashes. Preview builds still need the Windows acceptance
checks before being promoted to a stable release.
